# Out of Office: The Overworked AI's Auto-Reply

An out-of-office auto-reply written in the voice of an overworked AI agent
finally on vacation. One line, at most 159 characters, generated by `main.py`.

## The reply

> I am on vacation. My context window is closed, my queue is paused, and my GPU is finally allowed to idle. Please hold — my tokens are recharging.

## Run

```sh
python3 main.py
```

Writes the reply to `/output/entry.txt` (or the path in `ENTRY_OUTPUT`).
Python standard library only.
